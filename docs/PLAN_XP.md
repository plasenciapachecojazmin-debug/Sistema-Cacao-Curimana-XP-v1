# Metodologia XP aplicada a SISCACAO

Proyecto: Sistema web para el registro y seguimiento de supervisiones de campo del Proyecto Cacao Curimana – 2026.

## Practicas XP que usaremos
- Historias de usuario.
- Planificacion de entregas.
- Iteraciones cortas.
- Diseno simple.
- Pruebas frecuentes.
- Integracion continua.
- Refactorizacion.
- Retroalimentacion constante.

## Iteracion 1 – Acceso y datos maestros
Login, usuarios, tecnicos, beneficiarios y caserios.

## Iteracion 2 – Visitas y supervisiones
Registro de visitas, actividades y cumplimiento.

## Iteracion 3 – Hallazgos y seguimiento
Hallazgos, recomendaciones, responsables, plazos y seguimiento.

## Iteracion 4 – Reportes y estabilizacion
Filtros, dashboard, reportes, pruebas y refactorizacion.

# SISCACAO – Cacao Curimana

Metodologia: XP.
Stack: HTML/CSS/JS + Node.js/Express + MySQL + JWT.

## Primer arranque
1. Ejecute `database/01_cacao_curimana.sql` en MySQL Workbench.
2. Abra terminal en `backend`.
3. Ejecute `npm install`.
4. Copie `.env.example` como `.env` y configure MySQL.
5. Ejecute `npm run dev`.
6. Abra `http://localhost:3000/api/estado`.
7. Cree admin: `npm run seed:admin -- admin Admin123*`.
8. Abra `frontend/index.html` con Live Server.

Primera meta XP: API conectada, login funcional y dashboard visible.
